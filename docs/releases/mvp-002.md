# MVP-002 Release Notes

## Metadata
- MVP: `MVP2`
- Date: `2026-03-08`
- Status: `released`

## Summary
MVP2 delivered a full visual redesign of the public portfolio and admin CMS with a tokenized design system, responsive behavior upgrades, and accessibility baseline hardening.

## Scope
- Public site visual redesign (home, projects, blog index, blog post)
- Separate admin theme redesign (login and editor)
- Responsive and accessibility baseline improvements

## What shipped
- Tokenized style foundation in `src/css/style.css`.
- Compact mobile navigation with skip-link and keyboard support in `src/templates/layout.html`.
- Homepage hero and copy refinement in `src/pages/index.html`.
- Data-focused project cards and GitHub-generated metadata cards via `src/pages/projects.html` and `build.js`.
- Blog readability improvements including description, formatted date, and read-time via `src/templates/post.html` and `build.js`.
- Separate admin UI styling in `admin/login.html` and `admin/blog-editor.html`.
- Accessibility hardening: focus visibility, touch targets, reduced-motion support, live status regions.

## Behavioral changes
- Public navigation behavior is now menu-driven on mobile with Escape-to-close.
- Blog and projects metadata presentation is more structured and readable.
- Admin pages now use a dedicated visual language while preserving existing CMS API behavior.

## Verification run
