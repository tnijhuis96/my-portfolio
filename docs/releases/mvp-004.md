# MVP-004 Release Notes

## Metadata
- MVP: `MVP4`
- Date: `2026-03-20`
- Status: `released`

## Summary
MVP4 delivers build-time SEO foundations for urban-explore.com. Every published post now ships with Open Graph and Twitter card meta, JSON-LD Article structured data, and a canonical link. The build also produces a valid RSS 2.0 feed and an XML sitemap, making the site submittable to Google Search Console and subscribable via any feed reader.

## Scope
- RSS feed at `/feed.xml`
- XML sitemap at `/sitemap.xml`
- OG + Twitter card meta per post
- JSON-LD `Article` schema per post
- `<link rel="canonical">` on all generated pages
- `description` frontmatter warning in build output

## What shipped
- `build.js`: `SITE_URL` constant, extended `applyLayout()`, per-post head meta, postsMeta enrichment, RSS + sitemap generation
- `src/templates/layout.html`: `{{headMeta}}` placeholder added before `</head>`

## Behavioral changes
- Each post page `<head>` now contains canonical, OG, Twitter card, and JSON-LD markup
- Each static page and the blog index now contain a `<link rel="canonical">`
- Build output includes two new files: `dist/feed.xml` and `dist/sitemap.xml`
- Build logs a warning (not an error) when a post is missing a `description` field

## Verification run
- `npm run build`
- `npm run admin`
- `npm run preview:dist`

## Known limitations
- No `og:image` — deferred until a canonical image asset exists
- Google Search Console submission is a manual post-deploy step
- `about.html` (outside `src/pages/`) does not yet receive a canonical link

## Follow-up seeds
- Submit `sitemap.xml` to Google Search Console after deploy
- Add `og:image` once a default social card image is available (MVP5 or later)
- Consider `about.html` migration into `src/pages/` for full canonical coverage

## High-level files touched
- `build.js`
- `src/templates/layout.html`
