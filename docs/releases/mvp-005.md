# MVP5 Release Notes — Interactive Features & Search

## Status: draft
## Release date: TBD

---

## Summary
MVP5 adds static full-text search, a tag system, blog pagination, and a /now page to the portfolio. All features produce 100% static output — no new runtime infrastructure.

---

## What's new

### Pagefind full-text search
- `/search.html` — dedicated search page with Pagefind UI
- Search index built as part of `npm run build` via `npx pagefind --site dist`
- Search icon button (SVG, icon-only, accessible) added to main nav
- Index covers all published blog posts and static pages

### Tag system
- Posts can now declare `tags: [tag1, tag2]` in frontmatter
- Tag pills appear on individual post pages and blog index teaser cards
- Each tag generates a `/tags/{slug}/` index page listing relevant posts
- `/tags/` provides an all-tags overview page
- All tag pages included in `sitemap.xml`

### Blog pagination
- Blog index now paginates at 5 posts per page (configurable via `POSTS_PER_PAGE` env var)
- Page 1: `/blog/` — Page 2+: `/blog/page/{n}/`
- Prev/Next navigation added to each blog page
- All paginated URLs included in `sitemap.xml`

### /now page
- `/now.html` — manually maintained page describing current learning focus and active projects
- Included in `sitemap.xml`
